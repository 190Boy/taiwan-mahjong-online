# 🀄 台灣十六張麻將・線上房號對戰

在瀏覽器就能玩的台灣十六張麻將。開房拿到 **4 位數房號**，朋友輸入房號就能一起打；人數不夠時**空位由電腦補上**（2～3 個人也能玩）。也保留「單機玩（對電腦）」模式。

**直接玩**
- GitHub Pages（單機秒開，線上模式自動連到 Render 伺服器）：<https://190boy.github.io/taiwan-mahjong-online/>
- Render（同一套畫面，由伺服器直接提供）：<https://mahjong-online-wee6.onrender.com>

單機與線上是**同一份程式碼**（`docs/` 資料夾）：Render 用 `server.js` 提供它，GitHub Pages 直接發佈 `docs/`。
從 Pages 打開時，線上模式會連 `wss://mahjong-online-wee6.onrender.com/ws`；要換伺服器可在網址加 `?server=wss://你的主機/ws`。

- 伺服器負責所有牌局邏輯（洗牌、判胡、計台），每個人只會收到自己的手牌，無法作弊
- 吃／碰／槓／胡、自摸、補花、流局、台數計算、連莊與累計分數
- 出牌限時 20 秒、吃碰槓胡限時 9 秒（畫面有倒數，時間到自動處理）
- 重新整理或斷線：同一支手機／電腦再打開網址，會自動回到原本的座位；斷線期間由電腦代打。回座位只認這台裝置存的通行碼（token），別人知道房號和你的名字也搶不走座位；換手機就只能用新座位加入（大廳階段離線超過 1 分鐘、房間又滿了時，座位會讓給新玩家）
- 防猜房號：每條連線每分鐘最多試 8 次加入、同一個 IP 10 分鐘內「找不到房號」超過 12 次就暫時擋下；開房、訊息頻率也有上限
- 角色頭像（眨眼、搖頭晃腦、胡牌開心、放槍難過）、音效與國語喊牌在每個人自己的裝置上播放
- 房間沒人在線 10 分鐘後自動清除；分頁切到背景超過 10 分鐘、或 30 分鐘沒操作會自動斷線（不會讓免費主機一直醒著）
- 規則：搶槓、天胡、地胡、八仙過海、七搶一、獨聽、嚦咕嚦咕；平胡要兩面聽；摸牌後任何一輪都能加槓／暗槓（台數表見下方）
- 電腦難度：簡單／普通／困難（會看現物、筋、牌河做防守；困難另外會積極吃碰搶速度）。用 `npm run ai-eval` 跑 4000 局比較：困難 > 普通 > 簡單
- 聽牌鎖定（自動摸打）：聽牌時按「🔒 鎖定聽牌」（或選牌時按「打出並鎖定」），之後摸到不能胡的牌自動打掉、吃碰槓自動略過；摸到或別人打出胡牌會停下來問你（可勾「自動胡」）。線上版由伺服器代為打牌，重新整理也會保持鎖定
- 線上語音通話：房間或牌桌按「🎤 加入語音」（按了才會問麥克風），可靜音、離開；頭像上顯示語音中／靜音／正在說話，點別人的圖示可以只在自己這邊關掉他的聲音。聲音是玩家之間點對點（WebRTC），不經過伺服器；直連不通（公司防火牆擋 UDP、有線和 Wi-Fi 分在不同網段…）時改走 TURN 中繼（含 `turns:443` TLS/TCP，看起來跟一般 HTTPS 一樣）。連不上會在畫面顯示原因，點「語音連線失敗」的圖示會重試；瀏覽器主控台（F12）有一行 `[voice] 連線失敗 {...}` 寫著詳細資料（雙方收集到哪些連線候選）。設定見下方「語音中繼（TURN）」
- 離開／解散牌桌：房間畫面或牌桌上方「🚪 牌桌」。成員「離開牌桌」→ 回到大廳（牌局中會先確認，座位由電腦代打到這局結束；大廳中座位空出來），原本的通行碼作廢、語音關閉。房主可以「解散牌桌」→ 所有人回到大廳並看到「房主解散了牌桌」，房間刪除；房主自己離開時房主交給其他真人，沒有真人了房間就刪除
- 10 位角色各有自己的聲音：喊吃／碰／槓／胡、報牌、快捷聊天都用該座位角色的聲音（線上每台裝置都跟著各座位的頭像），選角色時可按 🔊 試聽。聲音是預先用免費的 edge-tts 神經語音產生、再用 ffmpeg 調音高語速的 mp3（`docs/voices/`，約 1.4 MB，每位角色約 140 KB，用到才載入）；還沒載入或載入失敗時改用裝置內建語音，依角色換聲音、音高、語速。重新產生：`python3 -m venv venv && venv/bin/pip install edge-tts && venv/bin/python tools/gen_voices.py`（需要 ffmpeg）
- 線上快捷聊天（固定短語＋表情，會顯示對話泡泡）
- 戰績：單機每個角色的戰績、線上本房計分板、自己的線上生涯戰績（存在瀏覽器裡）

## 台數表（本遊戲採用的規則）

底 300、每台 100；莊家另加 1 台，連 N 拉 N 再加 2N 台。同一手牌有多種拆法時，取台數最高的拆法。

| 台數 | 牌型 |
|---|---|
| 1 | 莊家、門清、自摸、三元牌刻子（每副）、圈風刻、門風刻、正花、獨聽、搶槓、槓上開花、海底撈月、河底撈魚 |
| 2 | 平胡、全求人、三暗刻、花槓 |
| 3 | 門清自摸（門清＋不求＋自摸，取代門清與自摸） |
| 4 | 碰碰胡、混一色、小三元 |
| 5 | 四暗刻 |
| 8 | 清一色、大三元、小四喜、五暗刻、嚦咕嚦咕、八仙過海、七搶一 |
| 16 | 字一色、大四喜、地胡 |
| 24 | 天胡 |

**平胡（2 台）**：五副都是順子、沒有字牌、沒有花、不是自摸，而且必須是**兩面聽**——胡的那張牌落在手上某個順子的頭或尾，且那個順子不是「12 等 3」或「89 等 7」的邊張。單吊、嵌張、邊張、對碰（雙碰）、延伸單吊（如 4567 等 4/7）都不算；只聽一張（獨聽）也不算。可另加門清 1 台。胡的牌有多種看法時（例如 23456 胡 4），只要有一種是兩面就算。

**獨聽（1 台）**：打出前只聽一種牌（單吊、嵌張、邊張）。以「聽幾種牌」判斷，和平胡互斥。

**嚦咕嚦咕（8 台）**：7 個**不同**的對子＋1 個刻子，共 17 張。
- 必須門清：有吃、碰、明槓就不成立；**暗槓也不算**（槓出去的牌不能當對子或刻子，手上 4 張一樣也不能當兩對）。
- 門清是成立條件，不另計門清；自摸只加自摸 1 台（不算門清自摸 3 台）。
- 可另加：天胡／地胡、混一色／清一色／字一色、刻子是三元牌或圈風／門風、正花／花槓、獨聽（例如 1 刻＋6 對＋1 張單張只聽那一張）、搶槓、槓上開花、海底撈月、河底撈魚。
- 不另計：平胡、碰碰胡、三／四／五暗刻。
- 同時能當一般胡牌時，取台數高的算法。
- 參考：常見的台灣規則（例如 PTT MJ 板〈16 張台灣麻將算牌規則〉、維基台灣麻雀計番）多半寫「8 台、必須門清、不計門清，刻子是有價字牌加計，獨聽／混一色／清一色／字一色加計」，本遊戲照這套；各地場規不同，可以再改。

## 部署到 Render（免費）— 一步一步來

> 需要：一個 GitHub 帳號、一個 Render 帳號（可直接用 GitHub 登入）。不用寫程式。

### 方法 A：Blueprint 一鍵部署（推薦）

1. 打開 <https://dashboard.render.com>，用 **GitHub 帳號登入**。
2. 右上角按 **New ＋** → 選 **Blueprint**。
3. 第一次會請你連結 GitHub：按 **Connect GitHub**，允許 Render 讀取 `taiwan-mahjong-online` 這個 repo。
4. 在清單中選 **taiwan-mahjong-online** → 按 **Connect**。
5. Render 會讀到專案裡的 `render.yaml`，顯示一個名為 `mahjong-online` 的服務（Free 方案）。按 **Apply / Deploy Blueprint**。
6. 等 2～5 分鐘，狀態變成 **Live** 就完成了。

### 方法 B：手動建立 Web Service

1. Render 右上角 **New ＋** → **Web Service**。
2. 選 **Build and deploy from a Git repository** → 選 `taiwan-mahjong-online` repo → **Connect**。
3. 依下表填寫，其他保持預設：

| 欄位 | 填這個 |
|---|---|
| Name | `mahjong-online`（隨意，會變成網址的一部分） |
| Region | Singapore（離台灣最近） |
| Branch | `main` |
| Runtime / Language | `Node` |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type | **Free** |

4. （選填）Advanced → Health Check Path 填 `/healthz`。
5. 按 **Create Web Service**，等狀態變成 **Live**。

### 開始玩

- 網址在服務頁面左上角，長得像 `https://mahjong-online-xxxx.onrender.com`。
- 把網址傳給朋友。一個人按 **開房**，把房號（或「複製邀請連結」）傳給大家，其他人輸入房號按 **加入房間**，房主按 **開始**。

### 關於免費方案

- 免費主機約 **15 分鐘沒人使用會睡著**，下次打開要等 **30～60 秒**喚醒（畫面會顯示「伺服器喚醒中…」，等一下就好）。
- 主機重新啟動（例如睡著、更新程式）時，進行中的房間會消失，重新開房即可。

### 之後要更新程式

改好的檔案推到 GitHub 的 `main` 分支，Render 會自動重新部署，GitHub Pages 也會自動更新（設定：Settings → Pages → Deploy from branch → `main` / `/docs`）。

## 在自己電腦上測試（給開發者）

```bash
npm install
npm start            # 打開 http://localhost:3000
npm test             # 規則測試＋線上伺服器安全測試（幾秒鐘）
npm run bench        # AI 單次思考時間
npm run ai-eval      # 各難度同桌 4000 局（約 40 秒），胡牌率／放槍率／平均分數含 95% 信賴區間
```

可用環境變數：`PORT`（預設 3000）、`TURN_MS`（出牌時限，預設 20000）、`CLAIM_MS`（叫牌時限，預設 9000）、`ROOM_IDLE_MS`（空房清除時間，預設 600000），以及上面的 TURN 設定。測試：`npm test`（規則、伺服器、/ice）。

## 語音中繼（TURN）

伺服器的 `/ice` 會給瀏覽器 STUN＋TURN 的設定；TURN 帳密是伺服器當場產生的**短效帳密**（6 小時過期），金鑰不會送到瀏覽器。依下面順序選第一個有設定的（Render → 你的服務 → **Environment** 加環境變數）：

| 供應商 | 要設定的環境變數 | 說明 |
|---|---|---|
| Cloudflare Realtime TURN | `CF_TURN_KEY_ID`、`CF_TURN_API_TOKEN` | 需要免費的 Cloudflare 帳號：Dashboard → Realtime → TURN Server → Create，複製 Turn Token ID 和 API Token。每月 1000 GB 免費 |
| Metered | `METERED_DOMAIN`（例 `xxx.metered.live`）、`METERED_API_KEY` | 需要免費的 metered.ca 帳號（每月 500 MB 免費） |
| 自架 coturn | `TURN_URLS`（逗號分隔）、`TURN_SECRET` | coturn 開 `use-auth-secret` |
| 固定帳密 | `TURN_URLS`、`TURN_USERNAME`、`TURN_CREDENTIAL` | |
| （都沒設定） | — | 預設用免註冊的公用 Open Relay（`staticauth.openrelay.metered.ca`，含 80/443、UDP/TCP/TLS）。公用服務不保證穩定；設 `TURN_DEFAULT=off` 可以關掉、只用 STUN |

能直連時還是點對點，只有直連不通才會走中繼。
